# Plan: NZ Criminal Defence RAG — Query Generation System

## Objective
Develop the complete retrieval query generation prompt architecture for the NZ Criminal Defence RAG system. This system must:
- Parse uploaded disclosure documents
- Extract entities, charges, legal concepts, temporal facts, and procedural markers
- Generate optimised queries for all 3 knowledge bases
- Expand and reformulate queries for maximum retrieval accuracy
- Integrate metadata filters for precision legal search

## Deliverables
1. **Disclosure Parsing Prompt** — Extract structured information from disclosure
2. **Query Generation Engine Prompts** — Generate queries for Legislation, Case Law, and Police Manual KBs
3. **Query Expansion & Reformulation Prompts** — Multi-strategy expansion
4. **Metadata Filter Generation Prompt** — Time periods, courts, jurisdictions, charge types
5. **Full Pipeline Architecture Document** — Complete system integration guide

## Execution
Single comprehensive deliverable with multiple components. Will develop directly with subagent assistance for depth.
